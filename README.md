## Подробный разбор примеров

### 1. Маршрутизатор (Устройство)
* **Уровень OSI:** `Сетевой уровень (Network Layer / Layer 3)`
* **Обоснование:** Маршрутизатор — это ключевое сетевое оборудование, работающее на третьем уровне. Его главная задача — объединять различные сети, построенные на основе разных технологий. Он отвечает за глобальную логическую адресацию (IP-адреса) и определение оптимального маршрута пересылки пакетов в составной сети (маршрутизацию).

### 2. Веб-браузер и протокол HTTP (Программная система)
* **Уровень OSI:** `Прикладной уровень (Application Layer / Layer 7)`
* **Обоснование:** На этом уровне работает пользовательское программное обеспечение. Браузер (например, Chrome или Firefox) взаимодействует напрямую с прикладным протоколом HTTP/HTTPS для запроса и передачи гипертекстовых Web-страниц, предоставляя сетевую услугу непосредственно конечному пользователю.

### 3. Коллизия данных (Сетевая ошибка)
* **Уровень OSI:** `Канальный уровень (Data Link Layer / Layer 2, подуровень MAC)`
* **Обоснование:** Коллизия возникает в разделяемой среде передачи данных (например, в классическом Ethernet или Wi-Fi), когда два или более устройства начинают вести передачу кадров одновременно. Сигналы накладываются друг на друга и искажаются. Борьбой с коллизиями и координацией совместного доступа к общей среде занимается подуровень управления доступом к среде (MAC) канального уровня.

### 4. Протокол шифрования TLS / SSL (Система/Протокол)
* **Уровень OSI:** `Уровень представления (Presentation Layer / Layer 6)`
* **Обоснование:** Этот уровень отвечает за согласование синтаксиса и семантики передаваемых данных. Протоколы TLS и SSL обеспечивают шифрование и дешифрование информации, гарантируя безопасность и преобразуя данные в понятный для взаимодействующих систем формат перед их передачей на нижние уровни.

### 5. Сетевой кабель «Витая пара» / Радиоволны Wi-Fi (Объект/Среда)
* **Уровень OSI:** `Физический уровень (Physical Layer / Layer 1)`
* **Обоснование:** Медный кабель, оптическое волокно или радиоволны представляют собой физическую среду передачи данных. Задача этого уровня — передача необработанного потока битов (0 и 1) путем их представления в виде физических сигналов (электрических импульсов или радиоволн). Никакой логической структуры (кадров, IP-адресов) на данном этапе еще не существует.
